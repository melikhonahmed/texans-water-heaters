name: Texans visual direction
description: The preferred visual direction for the Texans Water Heaters site after rejecting generic marketing-template treatments.
---

The Texans Water Heaters site should feel like a restrained, premium local service brand: clean composition, strong typographic hierarchy, deliberate use of the supplied vehicle/logo asset, and clear conversion moments. Avoid stacking stock-photo overlays, blueprint textures, decorative cards, and generic AI-marketing patterns.

**Why:** The user explicitly rejected multiple template-like redesigns as looking bad; a simpler brand-led composition tested better visually.

**How to apply:** Start with the real Texans asset and service context, then use whitespace, contrast, and one strong hero idea before adding decorative treatments.
